# TV Sticker Art — Drop Real PNGs Here

The game shows emoji for these characters until you add real art.
To upgrade a sticker, save a **transparent-background PNG** in this folder
named exactly like the sticker's id, then reload the game — no code edits needed.

## How to add art
1. Find or make a transparent PNG (ideally 400–800px on the longest side).
2. Name it `<id>.png` from the table below and put it in this `stickers/` folder.
3. Reload the page. Stickers with art switch from emoji to your image automatically.
4. Missing files are fine — the emoji stays as the fallback, nothing breaks.

> ⚠️ Licensing: Peppa Pig, Bluey, Baby Shark, Sharkdog/Finny, Gumball, and
> We Bare Bears are copyrighted. Only use art you made yourself, art the
> rights-holder released for reuse, or art you have permission to use.
> Random "free PNG" sites host unlicensed copies — downloading those into a
> published game can infringe. Keep this game personal unless every file's
> license is clear.
